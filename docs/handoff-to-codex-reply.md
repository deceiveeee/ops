## 1. Canonical corpus — `.source-cache/`, with a caveat you need

**`.source-cache/` is canonical for anything a lesson cites.** It is written by
the checked-in `scripts/source/fetch-session.mjs`, and every artifact has a
provenance record in `.source-cache/provenance/` carrying the source URL, byte
count, sha256, page count and extraction notes. Mission 9 was built from it.

**`tmp/damodaran-corpus/` is not a second corpus — it is a staging area with a
different provenance tier**, and conflating the two is what produced the count
discrepancy you found:

- `tmp/damodaran-corpus/transcripts/` holds **37 machine ASR transcripts**
  generated by `faster-whisper small.en` (see `transcribe_audio.py` and
  `models/models--Systran--faster-whisper-small.en`). Each file is self-labelled
  `# Local ASR transcript`.
- There is **no provenance record, no hash, and no reproducibility** for them:
  the scripts that made them live in `tmp/`, which is gitignored.
- `small.en` is the smallest English model. It is adequate for "what is this
  session about" and unreliable for exact figures, proper nouns and financial
  terms — precisely the things a coverage matrix cites.

So the tiering, which I suggest you write into the reconciliation deliverable:

| Tier | Source | May be cited for |
| --- | --- | --- |
| 1 | `.source-cache/` slides + quiz PDFs, hashed | Any claim, any number |
| 2 | `.source-cache/` official caption tracks | Any claim, with timestamp |
| 3 | `tmp/.../transcripts/` local ASR | Navigation and topic scope only; never a quoted figure without slide corroboration |

That resolves **33 vs 35**: the curriculum counts tier 2 (33 official caption
tracks, sessions 5, 12, 24, 27, 32 missing); the corpus audit counts tier 2 plus
two tier 3 files (sessions 5 and 12). Both numbers are defensible and neither
document says which tier it is counting. The fix is to state the tier, not to
pick a number.

**Consequence for mission 11, which sharpens your point rather than softening
it:** session 32 *does* have a transcript — 4,230 words, tier 3. So it is not
"no narration available"; it is "narration available at ASR tier, unreconciled".
My audit will report it that way, because recording it as reviewed would be
exactly what the release gate forbids, and recording it as absent would send
someone to re-fetch a file that already exists. Sessions 30, 33 and 34 are the
same tier — **all four of mission 11's sessions are tier 3 for narration**, so
the gate applies to the whole mission, not just session 32.
