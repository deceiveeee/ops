# Damodaran 38-session to Portfolio Builder mission map

Status: **Validated against all 38 slide decks, tests, and solutions and 35 narrations; narration reconciliation remains for Sessions 24, 27, and 32**

## 1. Mapping rule

The learner follows one ten-mission Portfolio Builder. Damodaran sessions are evidence sources, not required modules and not a second course direction.

A source concept enters the required path only when it helps the learner make, explain, implement, or monitor a portfolio decision. Strategy-specific mechanics become optional investigations. The original session remains available in the source library regardless of placement.

The complete source and defect audit is in `docs/source-audits/damodaran-investment-philosophies-corpus-audit.md`.

## 2. Cross-session prerequisite map

| Knowledge stage | Source support | What must be learned before moving on |
| --- | --- | --- |
| Investor and process | Sessions 1 and 38 | Goal, horizon, liquidity, tax/account context, capacity, behavior, and time available precede strategy choice. |
| Instrument and portfolio risk | Sessions 2–3 | Bond and equity risks, diversification, and required return precede allocation and sizing. |
| Business evidence and value | Sessions 4–5 | Cash flow, growth, reinvestment, risk, and price consistency precede security selection. |
| Strategy feasibility | Sessions 6–8 | Costs, taxes, correction mechanism, evidence design, bias, and execution precede any claim of edge. |
| Conditional active approaches | Sessions 9–29 | Momentum, value, growth, information, and arbitrage are alternative hypotheses, not a chain of beginner prerequisites. |
| Timing policy | Sessions 30–34 | The learner needs a strategic allocation before deciding whether any tactical deviation is allowed. |
| Implementation and final fit | Sessions 35–38 | Passive/active choice, vehicle selection, persistence, cost, and fit complete the policy and monitoring loop. |

This map changes Damodaran’s source order in one important way: Session 38’s investor-fit material moves to Mission 1 and returns in Mission 10. A learner should know the investor before choosing a philosophy, not only at the end of the course.

## 5. Optional investigation index

These labels organize the source library only; they are not learner modules and do not appear in core progress:

- momentum, temporal patterns, and technical analysis — Sessions 9–11;
- value approaches — Sessions 12–16;
- growth, small-company, IPO, GARP, and venture approaches — Sessions 17–21;
- information and event approaches — Sessions 22–26;
- pure, near, and speculative arbitrage — Sessions 27–29;
- market timing and market valuation — Sessions 30–34;
- manager evidence and passive implementation — Sessions 35–37.

An investigation opens only after the learner reaches the mission decision it informs. It returns to that decision with a concrete artifact, such as an edge test or rejection rule.

## 6. Architecture decision

The former five “source families” remain useful only as an internal audit shorthand. They are removed from learner-facing hierarchy. The only top-level learning direction is:

**mandate → asset roles → allocation/risk → evidence → value → passive/edge decision → holdings → sizing → operating rules → defense**
